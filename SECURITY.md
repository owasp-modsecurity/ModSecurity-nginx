# Security Policy

## Supported Versions

The latest versions v1.0.X are supported.

## Reporting a Vulnerability

Please do not report security issues publicly (no GitHub issues, pull requests or mailing lists).

Report them privately by opening a [draft security advisory](https://github.com/owasp-modsecurity/ModSecurity-nginx/security/advisories/new) on GitHub. The maintainers triage the report there, coordinate a fix with you
and publish the advisory together with the fixed release. Reporters are credited in the published advisory.

If you cannot use GitHub, email modsecurity@owasp.org instead.
